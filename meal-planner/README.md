# Meal Planner Frontend

The React 18 client for the Personalized Meal Prep & AI Nutrition Platform.

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite dev server (runs on http://localhost:5173)
npm run dev

# Build for production
npm run build
```

> **Note:** For full AI functionality (AI Smart Plan, Photo Analyzer, Voice Food Logging), ensure the Express backend in `../server` is running on port 3001 with a valid `ANTHROPIC_API_KEY`. See the root [README.md](../README.md) for full instructions.
